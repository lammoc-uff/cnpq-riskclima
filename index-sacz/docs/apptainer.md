# SACZ index workflow

This document describes the workflow used to preprocess atmospheric data and
calculate the South Atlantic Convergence Zone (SACZ) index from ERA5 and CMIP6
datasets.

The workflow is divided into two main stages:

1. preprocessing the atmospheric fields required by the SACZ index; and
2. applying the statistical model used to calculate the daily index for the
   three SACZ regions (`AB`, `C`, and `DE`).

Separate preprocessing scripts are used for ERA5 and CMIP6 because the two
datasets differ in storage format and data access. After preprocessing, both
workflows generate the atmospheric time series required by the SACZ index
calculation.

## CMIP6 preprocessing

Script: `cmip6_process_sacz_index.py`

The CMIP6 preprocessing script prepares the atmospheric fields required by the
SACZ index from CMIP6 Zarr stores.

For a selected model, experiment, and year, the script:

1. locates the Zarr stores for zonal wind (`ua`), meridional wind (`va`),
   vertical pressure velocity (`wap`), and geopotential height (`zg`);
2. selects the required pressure levels at 200, 500, and 850 hPa;
3. computes horizontal divergence and relative vorticity from the zonal and
   meridional wind components using MetPy;
4. clips each atmospheric field to the polygons used by the SACZ index;
5. calculates daily spatial means for each index subregion; and
6. saves one CSV file for each variable and pressure level.

The expected CMIP6 Zarr directory structure is:

```text
{SOURCE_ID}/{EXPERIMENT_ID}/day/{variable_id}/{grid_label}/*.zarr
```

The preprocessed files are written to:

```text
data/input/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/
```

The atmospheric input files required by the index calculation are:

```text
div200.csv
div850.csv
hgt500.csv
omega500.csv
uwnd200.csv
uwnd850.csv
vwnd200.csv
vwnd850.csv
vort200.csv
```

### 200 hPa pressure level

The SACZ index methodology uses upper-level atmospheric fields at 200 hPa.
When this level is not available in a CMIP6 model, the preprocessing script
allows 250 hPa to be used as a proxy without vertical interpolation.

The output filenames retain the 200 hPa reference used by the index
(e.g. `div200.csv` and `vort200.csv`).

The workflow was developed and tested with the following BCC-CSM2-MR
configurations:

```text
BCC-CSM2-MR  historical  1950-2014
BCC-CSM2-MR  ssp245      2015-2050
BCC-CSM2-MR  ssp585      2015-2050
```

The Zarr stores used during development are Zarr v3 and require Zarr 3.x and
Python 3.11 or later.

## CMIP6 SACZ index calculation

Script: `main_sacz_index_cmip6.py`

This script applies the SACZ statistical model to the CSV files generated by
`cmip6_process_sacz_index.py`.

The calculation follows four processing steps based on the fixed model
coefficients stored under `coefs/`:

1. **Normalization** — each atmospheric predictor is scaled using the
   corresponding reference minimum, maximum, and mean values.
2. **Principal component scores** — the normalized predictors are combined
   using the retained principal component weights.
3. **Linear combination** — selected principal components are combined using
   regional coefficients estimated by logistic regression.
4. **Logistic classification** — the resulting linear score is transformed to
   the `[0, 1]` interval using the logistic function.

The statistical model follows the SACZ-index methodology described by Nielsen
et al. (2019).

The script reads data from:

```text
data/input/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/
```

Intermediate results are written to:

```text
data/intermediatives/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/
    step1/
    step2/
    step3/
```

The final daily SACZ index for each region is written to:

```text
output/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/
    AB.csv
    C.csv
    DE.csv
```

## ERA5 download and preprocessing

Script: `era5_download_process_sacz_index.py`

The ERA5 preprocessing workflow downloads the pressure-level atmospheric
fields required by the SACZ index from the public ARCO ERA5 Google Cloud
bucket.

The required variables and pressure levels are:

```text
vertical_velocity     500 hPa
geopotential          500 hPa
u_component_of_wind   200 hPa
v_component_of_wind   200 hPa
u_component_of_wind   850 hPa
v_component_of_wind   850 hPa
```

For each day of the selected year, the script:

1. downloads the required ERA5 NetCDF files;
2. calculates daily means using CDO;
3. assigns pressure-level metadata required by the processing tools;
4. converts geopotential (`m² s⁻²`) to geopotential height (`m`);
5. computes horizontal divergence and relative vorticity from the wind fields;
6. merges the daily fields into yearly NetCDF files; and
7. calculates spatial means over the SACZ index regions.

The script uses the `ERA5_YEAR` environment variable to select the year to be
processed.

Raw and intermediate NetCDF files are stored under:

```text
data/raw/era5/{YEAR}/nc/
```

The processed SACZ input time series are written to:

```text
data/input/era5/{YEAR}/
```

The resulting CSV files follow the same variable naming convention used by the
SACZ index calculation:

```text
div200.csv
div850.csv
hgt500.csv
omega500.csv
uwnd200.csv
uwnd850.csv
vwnd200.csv
vwnd850.csv
vort200.csv
```

## ERA5 SACZ index calculation

Script: `main_sacz_index.py`

This script calculates the daily SACZ index from the preprocessed ERA5
atmospheric time series.

The target year is read from the `ERA5_YEAR` environment variable. For each
year, the script reads the atmospheric predictors from:

```text
data/input/era5/{YEAR}/
```

It then applies the same four-stage statistical model used by the CMIP6
workflow:

1. min-max scaling and reference-mean adjustment;
2. principal component weighting;
3. regional linear combination using the model coefficients; and
4. logistic transformation of the resulting score.

Intermediate files are written to:

```text
data/intermediatives/era5/{YEAR}/
    step1/
    step2/
    step3/
```

The final daily index is saved separately for the three SACZ regions:

```text
output/era5/{YEAR}/
    AB.csv
    C.csv
    DE.csv
```

## Workflow summary

The ERA5 and CMIP6 workflows use different preprocessing procedures but
produce equivalent atmospheric input variables for the SACZ statistical model.

```text
ERA5
  |
  +-- era5_download_process_sacz_index.py
  |      |
  |      +-- data/input/era5/{YEAR}/*.csv
  |
  +-- main_sacz_index.py
         |
         +-- output/era5/{YEAR}/{AB,C,DE}.csv


CMIP6
  |
  +-- cmip6_process_sacz_index.py
  |      |
  |      +-- data/input/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/*.csv
  |
  +-- main_sacz_index_cmip6.py
         |
         +-- output/cmip6/{SOURCE_ID}/{EXPERIMENT_ID}/{YEAR}/{AB,C,DE}.csv
```

The coefficient files under `coefs/` are shared by the statistical calculation
and should remain unchanged unless the SACZ model itself is recalibrated.
