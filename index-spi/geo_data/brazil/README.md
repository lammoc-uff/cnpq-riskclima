# Brazil country boundary

This directory contains the 2025 Brazil country boundary published by the Brazilian Institute of Geography and Statistics (IBGE). The workflow uses this boundary to mask CMIP6 and ERA5 precipitation grids before calculating SPI. The source data use the SIRGAS 2000 geographic coordinate reference system.

The following files form one shapefile dataset and must remain together:

- `BR_Pais_2025.shp`
- `BR_Pais_2025.shx`
- `BR_Pais_2025.dbf`
- `BR_Pais_2025.prj`
- `BR_Pais_2025.cpg`
