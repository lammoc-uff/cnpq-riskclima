# raw_data

This directory stores input and reusable intermediate files for the ERA5 XHWI workflow.

Expected calibration file:

- `xhwi_era5_calib_t2m_max_1961-1990.nc`: daily maximum 2 m temperature derived from hourly ERA5 `t2m` for the 1961-1990 calibration period.

The operational path is configured in `scripts/src/config/settings.py`.
